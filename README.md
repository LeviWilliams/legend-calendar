# React Native Legend Calendar

An opinionated fork of Marcelo Prado's [flash-calendar](https://github.com/MarceloPrado/flash-calendar) library which is built on top of [legend list](https://github.com/LegendApp/legend-list) instead of flash list and is heavily optimized. Credit to Marcelo for the awesome original library - I am just iterating on his work with legend-list for my own use cases.

## Key Features

- 🚀 Built on top of [legend list](https://github.com/LegendApp/legend-list) for optimal performance
- 📱 iOS and Android support
- ⚛️ React Compiler optimized source code 
- 🎨 Easy to customize and extend
- 🗓️ Infinite scrollable calendar support
- 📦 Tiny bundle size

You can find the Legend Calendar documentation [on the website](https://leviwilliams.github.io/legend-calendar/).
